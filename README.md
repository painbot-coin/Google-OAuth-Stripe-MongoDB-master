# Google OAuth + Stripe + MongoDB

Full-stack app: React Redux client and a Node/Express API. Users sign in with Google, pay with Stripe, and persist in MongoDB.

## What is in here

- `client` — React Redux frontend
- `config`, `routes`, `models`, `services`, `middlewares` — Express API
- Env-based secrets (see `.gitignore`)

## Stack

Node.js, Express, React, Redux, Google OAuth, Stripe, MongoDB
